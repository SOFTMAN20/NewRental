## API Testing Examples

### Get All Properties
```sql
SELECT * FROM properties WHERE status = 'active';
```

### Get Properties by University
```sql
SELECT p.*, u.name as university_name 
FROM properties p
JOIN universities u ON p.university_id = u.id
WHERE u.abbreviation = 'UDSM';
```

### Get Affordable Properties (< 200K)
```sql
SELECT * FROM properties 
WHERE monthly_rent < 200000 
AND status = 'active'
ORDER BY monthly_rent;
```

### Get Female-Only Properties
```sql
SELECT * FROM properties 
WHERE gender_restrictions = 'female_only'
AND status = 'active';
```
